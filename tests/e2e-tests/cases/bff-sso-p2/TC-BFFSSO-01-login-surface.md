# TC-BFFSSO-01 — 登录页用户表面

截图目录：`tests/e2e-tests/results/bff-sso-p2/`
前置依赖：BFF 9390、Vite 9391 运行；`bff/data/bff-tenants.json` 租户 `0` 为企业版。
隔离声明：只读页面，不创建账号、不提交登录（R3）；URL 带 `e2e-` 仅用于无副作用探测（R5）。
原生弹窗：无。
R6 现状口径：本机无 IdP，渠道按钮跳转不做真实完成，仅验证入口与离开页面。

## TC-BFFSSO-01-01 未登录访问根路径

| 项 | 内容 |
|---|---|
| 目的 | 未登录用户被引导到登录页，账号密码入口可用 |
| 前置 | 清空 `imt_token` Cookie；SSO 开关关闭（默认） |
| 数据 | 无 |
| 优先级 | P0 |
| 关联手册 | §1、§2、§6 |
| 步骤 | 1. 打开 `http://localhost:9391/`；2. 等待跳转完成 |
| 预期 | 落到 `/login`；账号密码表单可见；不出现 SSO 按钮；控制台无未捕获错误 |
| 截图 | `TC-BFFSSO-01-01.png` |
