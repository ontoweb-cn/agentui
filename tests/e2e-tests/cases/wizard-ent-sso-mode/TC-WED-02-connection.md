## TC-WED-02-01 SSO 模式只采集统一认证信息

| 项 | 内容 |
|---|---|
| 目的 | 手册 §4.1；设计 §10.4 |
| 优先级 | P0 |
| 步骤 | 选「企业版（SSO模式）」→ 下一步 |
| 预期 | 第 3 步标题为「统一认证设置」；字段只有：认证网关地址、网关服务密钥、登录渠道、公开来源地址、引导密钥、会话过期后静默重登。**不出现**后端名称、租户 ID 输入框、「启用统一认证」开关、「跳过」。步骤条第 3、4 步为「统一认证 / 验证」 |

## TC-WED-02-06 第 3 步无重渲染循环

| 项 | 内容 |
|---|---|
| 目的 | 设计 §10.8（回归） |
| 优先级 | P1 |
| 步骤 | 停留在第 3 步不做任何操作 10 秒，观察 Performance 面板与 localStorage |
| 预期 | 没有持续的渲染活动；`wizard-draft` 的写入次数不随时间增长 |
| 说明 | 该缺陷在浏览器里表现为持续重渲染并反复写 localStorage，组件测试中表现为进程卡死；已随 v1.3 修复 |
