# 用户手册 — 聊天助手设置:联网搜索与保存错误提示(module: ragflow-p1-batch)

> 日期:2026-11-22;九步交付法步骤 2 产物。面向业务使用者,口径与代码实现一一对应(见关联测试与提交)。
> 关联:[任务清单 v3](./ragflow-ui-alignment-followup-tasks.md) T2.1/T2.2/T2.3/T2.8/T2.9/T1.4、BFF 保存校验(T2.7)

## 1. 功能入口

打开任意聊天助手的对话页,点击右上角**齿轮图标**展开右侧"聊天设置"面板(宽 440px)。面板自上而下分为:

- **基础设置**:头像/名称/描述、模型设置(默认折叠,点"模型设置"展开采样参数)、开场白、数据集绑定;
- **高级设置**:默认折叠,点标题展开——含空响应、引用/关键词/语音开关、目录增强、**联网搜索**、元数据过滤、引用元数据、系统提示词、相似度阈值、Top N、多轮对话、知识图谱、重排、跨语言、动态变量。

## 2. 联网搜索配置

### 2.1 选择搜索服务商

在"高级设置"中找到**联网搜索服务商**下拉框,支持 14 家服务商(AnySearch、Brave、Exa、Firecrawl、Keirolabs、Linkup、Parallel、Perplexity、Querit、Search1API、SearchApi、Serply、Tavily、You.com),每项显示品牌图标与名称,支持按名称搜索过滤。

- 选定后,下方出现该服务商的 **API Key 输入框**(密码态显示),标签注明"〈服务商〉 API Key";
- 标签带红色 `*` 的是**必填**服务商(除 AnySearch 与 You.com 外均必填——这两家有无凭据可用模式);
- 输入框下方附服务商控制台链接,点击可跳转申请页面。

### 2.2 填写 API Key

| 情形 | 行为 |
|---|---|
| 选了必填服务商但未填 Key | 保存被阻止,Key 输入框下方与面板定位处出现红字提示"需要 API Key"(各语言) |
| 切换服务商 | 已填的其他服务商 Key **保留**(不丢失),再次切回时自动回填 |
| 清除所选服务商(下拉清空) | 所有已填 Key 仍保留在配置中,但联网搜索不可用;重新选择后恢复 |

### 2.3 老对话自动识别 Tavily

仅保存过 **Tavily API Key** 的历史对话(早期版本未提供服务商标选择),打开设置页时将**自动预选 Tavily** 并回填 Key。此时:

- 直接保存:配置中会首次写入"服务商=Tavily"(与原有行为兼容,Key 不变);
- 不想用 Tavily:手动改选其他服务商或清空选择即可。

新对话(未配置过任何 Key)打开时服务商为空,不自动预选。

## 3. 保存与错误提示

### 3.1 正常保存

填写完毕点击底部**保存**按钮,出现成功提示。保存内容含:名称、描述、数据集绑定、模型与采样参数、系统提示词、联网搜索配置等全部设置项。

### 3.2 保存失败时会发生什么

若必填项缺失(如系统提示词为空、必填服务商未填 Key、变量名为空等),点击保存后:

1. **所有折叠的设置分区自动展开**——错误不会藏在折叠面板里;
2. **页面自动滚动并居中定位到第一个出错字段**;
3. 出错字段下方显示具体红字原因(如"请输入!"、"需要 API Key"、"{knowledge} 占位符提示")。

连续多次点击保存,每次都会重新定位到首个错误,不会出现"点了没反应"的观感。

### 3.3 两类常见校验错误(业务口径)

| 错误 | 触发条件 | 如何修复 |
|---|---|---|
| 系统提示词需包含 {knowledge} | 已绑定数据集,但自定义系统提示词删掉了 `{knowledge}` 占位符 | 在系统提示词中加回 `{knowledge}`(召回内容将填充到该位置),或解除数据集绑定 |
| 空响应需清除 | 未绑定任何数据集,但填写了"空响应" | 清空"空响应"字段,或绑定至少一个数据集 |

## 4. 错误路径汇总

| 场景 | 预期表现 |
|---|---|
| 名称留空保存 | 红字"请输入!"于名称处,面板自动定位 |
| 系统提示词清空保存 | 红字"请输入!"于系统提示词处 |
| 必填服务商未填 Key | 红字于 Key 输入框,面板自动展开定位 |
| 动态变量名留空 | 红字于该变量行(变量名不可为空) |
| 绕过页面直接调接口保存非法配置(技术口径) | BFF 拒绝:未知服务商或必填 Key 缺失返回 400 及明确错误信息 |

## 5. 与旧版本的行为差异(升级须知)

1. 保存失败此前**部分静默**(错误渲染在折叠面板内看不见)→ 现在自动展开+定位;
2. 老对话设置页此前**看不到**已生效的 Tavily 联网开关来源 → 现在显式预选;
3. 直调接口提交非法服务商/缺 Key 配置此前被透传 → 现在被 400 拒绝(仅影响绕过页面的调用方,页面内操作无感)。
