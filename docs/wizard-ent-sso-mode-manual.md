# 用户手册 — 向导企业版双模式（SSO / 非 SSO）

> 模块:`wizard-ent-sso-mode`  
> 日期:2026-11-24（v1.3）  
> 口径真源:`docs/wizard-enterprise-sso-mode-design.md` v1.3 §10  
> 读者:实施首装的管理员（业务术语，不写实现细节）

---

## 1. 这是什么

首次安装（或管理端「添加后端」进入向导）时，在**选择类型**一步会看到两张企业版卡片。从 v1.3 起，两张卡走的是**两条不同的流程**：

1. **企业版（SSO模式）** — 用统一认证登录。向导里只填写认证网关和统一认证信息；企业后端由系统自动登记，不需要单独配置。  
2. **企业版（非SSO模式）** — 用成员账号密码登录。向导里只有后端连接信息，全程不涉及统一认证。

社区版 / HERMES / AgentScope 卡片行为不变，不在本手册范围。

---

## 2. 入口

| 场景 | 入口 | 预期 |
|---|---|---|
| 尚未完成首装 | 打开应用会进入向导 | 从欢迎页开始 |
| 已有后端仍要再配 | 管理语境打开 `/wizard?mode=add` | 可进入向导，不被踢回首页 |

步骤条均为六步，但第 3、4 步的名称不同：

- SSO 模式：欢迎 → 选择类型 → **统一认证 → 验证** → 确认 → 完成
- 非 SSO 模式：欢迎 → 选择类型 → **连接信息 → 探测** → 确认 → 完成

---

## 3. 选择类型

### 3.1 卡片顺序

1. 企业版（SSO模式）  
2. 企业版（非SSO模式）  
3. Intellect Community  
4. HERMES  
5. AgentScope

未选中任一卡时，「下一步」不可用。

### 3.2 两张企业卡的区别

| 卡片 | 徽章 | 说明内容 | 后端能力 / 默认端点 |
|---|---|---|---|
| 企业版（SSO模式） | SSO | 只讲统一认证登录 | 不显示 |
| 企业版（非SSO模式） | 密码 | 只讲成员账号密码登录 | 显示 |

非 SSO 卡的说明里不再出现「可稍后开启 SSO」之类字样。

### 3.3 已有企业后端时

从管理端「新增后端」进入、且系统里**已经登记过企业后端**时，SSO 模式卡不再出现，页面提示前往「系统管理 → 统一认证设置」调整。原因：这张卡会再登记一条企业后端并改写默认绑定，不适合在已有企业后端时使用。

### 3.4 切换卡片

从 SSO 模式改选非 SSO（或反过来）时，上一张卡的填写内容会被清空，不会带到下一张卡。

---

## 4. SSO 模式

### 4.1 统一认证设置（第 3 步）

| 配置项 | 说明 |
|---|---|
| 认证网关地址 | 必填。填网关基址（不是 WebUI 页面地址）；登录渠道与租户信息都从这里读取 |
| 网关服务密钥 | 必填。网关的服务密钥（API_SERVER_KEY）；统一认证的回调兑换与登录请求都以它鉴权。不会回显 |
| 登录渠道 | 点「获取登录渠道」读取网关已启用的渠道；勾选要展示在登录页的，一个都不勾 = 展示全部。配置不完整的渠道会标注原因且不可选 |
| 公开来源地址 | 预填当前站点地址。使用 `http://` 时提示：生产环境必须 https |
| 引导密钥 | 点「生成」产生随机密钥，复制到部署配置的 `BFF_SSO_STATE_SECRET`；仅在当前页面展示一次 |
| 会话过期后静默重登 | 默认开启 |

这一步**不会出现**：后端名称、租户 ID、「启用统一认证」开关、「跳过」按钮。

未填网关地址或服务密钥、未生成引导密钥、公开来源地址不合法时，「验证并继续」不可用。

### 4.2 验证（第 4 步）

进入本步自动验证，逐项给出结论：

| 检查项 | 通过 | 未通过时 |
|---|---|---|
| 认证网关可达 | 显示可达 | 提示检查网关基址是否填成了页面地址 |
| 企业租户 ID | 自动识别并显示 | 网关没有返回时出现手填框（32 位十六进制），填对才能继续 |
| 网关服务密钥 | 显示有效 | 网关明确拒绝时显示无效；网关没有可供校验的端点时显示「将在使用时验证」，不阻断 |
| 统一认证服务可用 | 显示可用 | 不可达时可重试；可用但渠道数为 0 时提示可稍后配置 |

### 4.3 确认与完成

- 确认页只显示统一认证摘要：类型、认证网关、租户 ID、登录渠道、公开来源地址、静默重登；按钮为「完成配置」。
- 完成页说明：统一认证配置已完成，企业网关已自动登记。
- 完成页给出需写入部署配置的环境变量片段（`BFF_SSO_*`，引导密钥以占位符显示）。
- **未写入环境变量并重启服务前，登录页不会出现统一认证渠道。**

---

## 5. 非 SSO 模式

- 第 3 步只有后端连接字段：后端名称、端点、凭据（Bearer Token）、Intellect 租户 ID（32 位十六进制，从网关部署配置复制）。
- 探测、确认、完成三步与其它后端类型一致。
- 全程不出现统一认证内容，完成页也没有统一认证环境变量。

以后要开启统一认证：用 SSO 模式完成首装；或安装后到「系统管理 → 统一认证设置」调整（引导密钥仍需在部署配置中提供）。

---

## 6. 运维安全注意（粘贴环境变量时）

1. **先看提示再粘贴**：完成页片段是「待写入」内容，不是系统已生效的配置。  
2. **核对每一行**：只应出现预期的 `BFF_SSO_*` / `BFF_PUBLIC_ORIGIN` 等键；若出现异常换行、陌生键名，**不要整段盲贴**。  
3. **公开来源地址**须是用户浏览器实际访问的站点源（含正确 https）；填错会导致回调失败。  
4. **引导密钥**只在向导页面展示一次：复制到密钥保管位置与部署配置，不要提交到 git。网关服务密钥与引导密钥都不会在接口响应中出现。  
5. 生产若 BFF 对公网暴露：须按设计 `wizard-enterprise-sso-mode-design.md` §9 完成 SSRF/片段消毒加固，并关闭对不可信来源的私网探测放行。

---

## 7. 登录页关系（首装之后）

- **SSO 模式**且环境已生效：登录页可同时看到**密码框**和**统一认证渠道按钮**（密码保留作运维破窗，不是缺陷）。  
- **非 SSO 模式**：只有密码登录。  
- 统一认证失败时的「联系管理员 / 未开通」等提示，见登录手册；本向导手册不重复。

---

## 8. 错误与边界

| 情况 | 用户可见预期 |
|---|---|
| 未选类型点下一步 | 下一步禁用或无法前进 |
| SSO 模式缺网关地址 / 服务密钥 / 引导密钥 | 无法进入验证；服务端同样拒绝 |
| 公开来源地址不合法 | 无法继续并提示 |
| 网关没有返回租户 ID | 验证步出现手填框，填对才能继续 |
| 网关拒绝服务密钥 | 验证步显示密钥无效，返回上一步修改 |
| 统一认证服务不可达 | 验证失败，可重试 |
| 已有企业后端时进入「新增后端」 | 看不到 SSO 模式卡，并有指引 |
| 旧草稿里只有「企业版」无模式区分 | 应重新选择类型，不能静默当成 SSO 模式 |

---

## 9. 明确不做（避免误解）

- 不会在完成页直接「已经登录进统一认证」。  
- 不会把成员令牌塞进浏览器给 HIEDU。  
- 社区版卡片不会出现企业统一认证配置。  
- SSO 模式不会关闭密码登录。  
- 完成 SSO 模式不等于免重启：引导密钥与环境变量仍需写入部署配置。
