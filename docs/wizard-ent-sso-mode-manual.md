> 模块:`wizard-ent-sso-mode`（v1.4 起本手册为**安装后管理页**口径；向导内不再配置 SSO）  
> 日期:2026-11-25  
> 口径真源:`docs/wizard-enterprise-sso-mode-design.md` v1.4 §11（§12 评审通过）  
> 读者:启用统一认证的管理员（业务术语，不写实现细节）

---

## 1. 这是什么

统一认证（SSO）让终端用户在登录页通过企业 IdP 免密进入。**v1.4 起 SSO 不在安装向导中配置**：向导只负责企业后端首装（网关地址 / 服务密钥 / 租户 ID）；SSO 的启用与调整全部在 **「系统管理 → 统一认证设置」** 完成，保存即时生效（无需重启）。

## 2. 前置条件（启用前一次性准备）

| # | 事项 | 说明 |
|---|---|---|
| 1 | 企业版首装 | 向导选 Intellect Enterprise 完成（网关地址、服务密钥、租户 ID 已入库） |
| 2 | 预置引导密钥 | 在部署配置中设置 `BFF_SSO_STATE_SECRET`（≥32 字符，静态值，如 k8s Secret）。**本页不展示/不修改该密钥** |
| 3 | IdP/网关侧登记 | provider（通常 `intellect-auth`）启用；`redirect_uris` 白名单包含「公开来源地址 + `/api/bff/auth/oauth/callback`」 |

## 3. 前置状态检测

页面顶部「前置状态」卡对默认租户绑定的企业后端做**实时检测**，点「重新检测」触发：

| 检查项 | 通过 | 未通过/无法判定时 |
|---|---|---|
| 认证网关可达 | ✓ | ✗：检查网关基址与后端绑定 |
| 企业租户 ID | 显示网关返回值 | 未返回：到「Harness 后端」修正 |
| 网关服务密钥 | 有效 | 网关拒绝（✗）或无法判定（?，将在使用时验证） |
| 统一认证服务 | 可用 + 渠道数 | 不可达：可稍后再试 |

`BFF_SSO_STATE_SECRET` 显示三态：**未设置 / 已设置 / 已设置但长度不足 32 字符**（只提示，永不回显值）。

## 4. 启用与配置

| 配置项 | 说明 |
|---|---|
| 启用统一认证登录 | 默认租户未绑定企业后端时开关**禁用**；密钥未就绪时保存会返回警示（仍写入，先提示） |
| 公开来源地址 | 用户实际访问的站点源（生产必须 https）；决定 OIDC `redirect_uri` |
| 登录渠道白名单 | 从网关渠道**预览勾选**（与手动输入联动）；全部不勾 = 展示全部可用渠道；配置缺失的渠道灰显不可选 |
| 会话过期后静默重登 | 默认开启 |

保存后**即时生效**；密码登录保留为运维破窗，不受影响。

## 5. 启用后验证

1. 新开页访问 `/login-next`：应出现 SSO 渠道按钮 + 密码框；
2. 走一次 SSO 登录：成功应有会话 Cookie；失败常见码见登录手册（`member_not_provisioned`=账号未开通，需按 HIEDU 对账/开通）。

## 6. 运维安全注意

1. 引导密钥只在部署配置中保管，不要提交 git、不要要求网关/监控记录配置变更明文；
2. 公开来源地址填错会导致回调失败——改动后务必走一次 §5 验证；
3. 生产 BFF 对公网暴露时：保持 `SSRF_ALLOW_PRIVATE_IP=false`。

## 7. 回滚

- 关闭开关（即时生效）= 登录页回到纯密码；
- 彻底回退配置：点「回落环境变量」清除运行时配置，回到部署 env 兜底。

## 8. 明确不做

- 本页不生成/展示/修改引导密钥；
- 不关闭密码登录；
- 不经 HIEDU 分发任何 team 凭证（HIEDU 职责=成员目录/对账键，见 status 文档 §1.3）。
