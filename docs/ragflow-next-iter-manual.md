# 用户手册 — 工程工具与任务页布局变更说明(module: ragflow-next-iter)

> 日期:2026-11-22;九步步骤 2。本批以工程交付为主:业务可见面变化很小。

## 1. 代码检查工具(T2.6)

开发者在仓库根执行 `npm run lint` 时:
- 仍会跑原有 **ESLint**;
- 额外串行跑 **oxlint**(更快的静态检查)扫描 `src/`。
- 任一门禁失败即整体失败。业务用户无感知。

错误路径:若 oxlint 报错,按终端文件/行号修复或按项目约定加入忽略(需评审,不可静默关掉安全类规则)。

## 2. 「任务」导航页(T2.5 第二步)

### 2.1 入口与行为(不变)

侧栏 **任务** → `/tasks` 列表;可切换聊天/智能体子区。列表搜索、分页、打开会话等业务行为与迁入前一致。

### 2.2 对开发者的变化

页面源码从 `src/pages/tasks` 迁到 `src/ee/pages/tasks`(agentui 私有 overlay)。路由 URL **不变**;仅内部 import 路径变为 `@/ee/pages/tasks`。

错误路径:若构建后 `/tasks` 空白,优先查 feature manifest 是否仍指向旧 `@/pages/tasks`(应已为零引用)。

## 3. 联网搜索 API Key 存储(T4.2 设计口径预告)

### 3.1 今天(用户可见)

设置页填写的各搜索服务商 API Key 随助手配置一起保存。切换服务商后,旧 Key 仍保留以便切回。分享页**看不到**任何 Key,只看到是否「可用联网」。

### 3.2 规划中(设计文档目标,本批不改现网行为)

未来 Key 将与普通配置分离存放:配置里只留「引用」,拉取配置时默认不回传明文;切换服务商不再依赖「整包里堆着多家 Key」。落地时间随后端 Go 化阶段,见设计文档。
