# 用户手册 — 安装向导(首次配置)

适用版本:本次交付后的 agentui v0.4.x。本文只描述用户可见行为,不涉及实现。
关联:调研笔记 `tests/e2e-tests/outline/wizard-sso-research.md`、设计文档 `docs/wizard-kag-to-sso-design.md`。

## 1. 入口

- **首次安装**:部署后首次打开应用,系统自动进入安装向导;
- **追加后端**:管理员在「系统管理 → Harness 后端」页点击"新增后端",进入同一向导(地址带 `mode=add`);
- 向导共 6 步:欢迎 → 选择类型 → 连接信息 → 探测 → 确认 → 完成;顶部步骤条显示当前进度(选「企业版(SSO模式)」时第 3、4 步为「统一认证 → 验证」,见 `wizard-ent-sso-mode-manual.md`)。

## 2. 选择后端类型(步骤 2)

系统提供 5 张卡片,单选;两张企业卡走不同的流程:

| 类型 | 说明 | 默认端点 | 能力标记 |
|---|---|---|---|
| 企业版(SSO模式) | 统一认证登录;只填写认证网关与统一认证信息,企业后端自动登记 | 不显示 | 不显示 |
| 企业版(非SSO模式) | 成员账号密码登录,团队/项目 + 多租户 | `http://localhost:9091` | 画布/知识库/多租户/模型管理 |
| Intellect Community | 社区版,纯 Agent 运行时(OpenAI 兼容) | `http://localhost:9091` | — |
| HERMES | HERMES 协议后端 | `http://localhost:9091` | — |
| AgentScope | AgentScope 多智能体框架 | `http://localhost:5000` | — |

> 说明:KAG 平台(MCP 协议族)不在向导中提供;如需接入,由管理员在系统管理中手工配置。

- 未选择类型时"下一步"不可用;
- 说明:Intellect RAG 不作为独立类型出现,它是企业版的画布/知识库插件,**由管理员后续在系统管理中配置**(见 §3.3 与 §7)。

## 3. 连接信息(步骤 3)

本步适用于「企业版(非SSO模式)」及其它后端类型;「企业版(SSO模式)」的第 3 步是「统一认证设置」,见 `wizard-ent-sso-mode-manual.md` §4。

### 3.1 通用字段(全部类型)

| 字段 | 规则 |
|---|---|
| 后端名称 | 必填;仅字母/数字/连字符,用于生成系统内部标识 |
| 端点 | 必填;http(s) 地址,选择类型时自动填默认值 |
| 凭据 | 按类型要求填 Bearer Token,或邮箱+密码 |
| 表单草稿 | 刷新页面后表单内容保留;**凭据(token/邮箱/密码)仅保存在当前浏览器标签页会话中**,关闭标签页即清除,不写入本地磁盘长期存储 |

### 3.2 企业版附加字段(非 SSO 模式)

| 字段 | 规则 |
|---|---|
| Intellect 租户 ID | 必填;32 位十六进制,从网关部署配置复制;填错时红字提示且不能下一步(SSO 模式下自动识别,见 `wizard-ent-sso-mode-manual.md` §4.2) |
| RAG 插件 | **不在向导中出现**;安装完成后由管理员在系统管理中配置(见 §7) |

### 3.3 统一认证(仅「企业版(SSO模式)」)

v1.3 起统一认证不再是连接表单里可跳过的区块,也没有启用开关:

- 选「企业版(SSO模式)」:第 3 步整步是「统一认证设置」——认证网关地址、网关服务密钥、登录渠道、公开来源地址、引导密钥、静默重登;不出现后端名称与租户 ID;
- 选「企业版(非SSO模式)」:全程不出现统一认证内容。

字段说明与验证、确认、完成页见 `wizard-ent-sso-mode-manual.md` §4。

## 4. 探测(步骤 4)

- 进入本步自动探测:校验端点可达并识别能力;
- 企业版额外校验网关基址(填成页面地址而非网关地址时给出明确提示);
- 探测成功:显示"后端可达"与发现的能力;继续进入确认;
- 探测失败:显示失败原因,可修改后"重试"或返回上一步;
- 短时间内频繁探测会被限流并提示稍后再试。

## 5. 确认(步骤 5)

- 汇总展示:名称/类型/端点/租户 ID(SSO 模式改为统一认证摘要);
- 点击"创建后端"完成配置;失败时显示原因,可返回修改;
- 成功后展示 **.env 配置片段**——只包含需要写入部署配置的项目(SSO 模式为统一认证相关配置,密钥以占位符显示)。后端凭据已存入系统的加密密钥库,片段里不再出现 Token 环境变量行;需复制到部署配置文件并按提示使配置生效。

## 6. 完成(步骤 6)

- 显示"配置完成",可进入首页;
- 若有非阻断提示(如"RAG 插件未配置:画布/知识库/记忆/模型管理在管理端补配前将不可用"),在本页列出;
- 未配置 RAG 插件不影响登录与基础使用;相关功能入口在补配前自动隐藏。

## 7. 安装后补配 RAG 插件(系统管理)

1. 进入「系统管理 → Harness 后端」,编辑目标企业版后端;
2. 填写 RAG 插件端点与 API Key,保存;
3. 画布/知识库等能力随即恢复,无需重跑向导。

## 8. 错误路径总览

| 场景 | 表现 |
|---|---|
| 端点不可达/凭据错误 | 探测失败 + 原因,可重试 |
| 端点指向受限地址 | 提示"URL 不安全"并给出放行说明 |
| 租户 ID 缺失/格式错误 | 红字提示,禁止下一步 |
| 后端名称重复 | 提示已存在且已就绪,拒绝重复创建 |
| 名称无有效字符 | 提示需包含字母或数字 |
| 邮箱/密码模式缺项 | 提示必填 |
| SSO 渠道拉取失败 | 提示稍后再试,不影响已填的其他统一认证项 |
| 渠道白名单含未知渠道 | 保存成功但给出非阻断警告(全部渠道可能不展示) |
| 密钥长度不足 | 禁止继续并提示 |
| 公开来源非法 | 禁止继续并提示 |
| 频繁探测 | 提示稍后再试 |

## 9. 统一认证设置(安装后调整)

入口:「系统管理 → 统一认证设置」(需管理员会话)。

| 能力 | 说明 |
|---|---|
| 查看生效配置 | 展示当前生效的启用状态/公开来源/渠道白名单/静默重登,并标注每项来源(管理端保存的运行时配置,或部署环境变量兜底) |
| 修改配置 | 编辑后保存,即时生效,无需重启服务 |
| 密钥管理 | 引导密钥(BFF_SSO_STATE_SECRET)属部署级敏感配置,**不在本页展示或修改**,仍由部署配置文件管理;开启统一认证但密钥缺失时,服务启动会明确报错 |
| 渠道白名单 | 逗号分隔的渠道 ID 列表;留空 = 不过滤(以网关 enabled/用途为准) |
