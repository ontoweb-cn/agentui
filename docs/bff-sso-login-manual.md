# 用户手册 — 企业版登录（SSO）

适用版本：agentui v0.4.x，企业版（`authMode=intellect-enterprise`）。本文只描述用户可见行为，不涉及实现。

## 1. 入口

打开应用根地址：
- 未登录 → 自动跳转登录页（`/login`）。
- 支持 `/login?tenant=<租户ID>` 指定租户（运营/多租户场景）。

登录页包含：
1. 账号密码表单（`disablePasswordLogin=true` 时隐藏）；
2. SSO 渠道按钮（该租户已在网关启用 OAuth provider 时出现）；
3. 注册入口（企业版需邀请码时按网关要求展示）。

## 2. 账号密码登录

| 项 | 说明 |
|---|---|
| 输入 | 登录名（企业版）或邮箱（社区版）+ 密码 |
| 成功 | 回到工作台首页，无需刷新 |
| 失败 | 凭证错误提示；频繁失败会被网关限流并提示稍后再试 |
| 记住我 | 仅影响本次浏览器偏好，不延长服务端会话 |

## 3. 统一认证（SSO）登录

### 3.1 发起

点击「Sign in with <渠道名>」：
1. 浏览器离开 agentui，跳到统一认证页面；
2. 若已有统一认证会话，可能**不再要求输入密码**；
3. 认证完成后自动回到工作台。

用户全程不需要填写或复制任何 Token。

### 3.2 渠道按钮何时出现

- 该租户在网关侧存在 provider，且 `enabled`、用途包含登录；
- 渠道缺少必要配置（如客户端 ID、授权地址）时**不展示**，但账号密码登录不受影响；
- 运营可通过全局应急开关临时下线全部 SSO 渠道。

### 3.3 失败提示

| 提示含义 | 用户动作 |
|---|---|
| 登录状态已失效，请重新登录 | 重新点击渠道按钮 |
| 账号已被禁用 | 联系管理员 |
| 账号尚未开通 | 联系管理员完成账号绑定 |
| 无权限登录该应用 | 联系管理员检查租户/身份绑定 |
| 请求过于频繁 | 稍后再试 |
| 认证服务暂时不可用 | 稍后再试或改用账号密码 |
| 登录请求已过期 | 重新点击渠道按钮 |

### 3.4 会话过期后的静默重登

- 会话过期后再次打开应用，可能直接回到工作台（统一认证仍有会话），无需输入密码；
- 统一认证也无会话时，会跳转统一认证登录页，最多一次；
- **主动登出后**再打开应用，会回到登录页，不会被自动登录。

## 4. 登出

点击头像 → 退出登录：
- 立即清除本应用登录态并回到登录页；
- 不会退出统一认证本身（该行为由统一认证平台决定，当前版本不做单点登出）。

## 5. 注册（企业版）

- 网关开启邀请制时，需要邀请码；
- 邀请码缺失/失效/已使用会给出对应提示；
- 注册成功后回到登录页，用新账号登录。

## 6. 运营开关（对用户可见的影响）

| 开关 | 用户可见表现 |
|---|---|
| 关闭 SSO | 登录页只剩账号密码 |
| 下线某渠道 | 该渠道按钮消失，其它渠道不受影响 |
| 关闭静默重登 | 会话过期后直接回登录页 |

## 7. 不在本手册范围

- 统一认证平台自身的密码找回、账号申诉；
- 单点登出（SLO）；
- 跨应用（如 aidevops）的免登录跳转。
