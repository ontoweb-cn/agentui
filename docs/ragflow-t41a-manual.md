# 用户手册 — 分享页联网开关与设置保存密钥(module: ragflow-t41a)

> 日期:2026-11-22;九步交付法步骤 2。面向业务使用者与联调方。
> 关联:清单 T4.1a;[聊天设置手册](./chat-settings-web-search-manual.md)

## 1. 分享页「联网搜索」开关何时出现

### 1.1 入口

将聊天助手通过「嵌入网站」生成的分享链接打开(`/chats/share?shared_id=…`),底部输入框旁出现联网相关控件的前提是:该助手**已配置可用的联网搜索服务商**。

### 1.2 判定口径(业务)

| 配置状态 | 分享页是否显示联网能力 |
|---|---|
| 未选服务商,且无任何 Key | 否 |
| 选了 AnySearch 或 You.com(可无 Key) | 是 |
| 选了其他服务商且填了对应 API Key | 是 |
| 仅有历史 Tavily Key、未写服务商字段(老数据) | 是(按 Tavily 可用) |
| 选了需 Key 的服务商但 Key 为空 | 否 |
| 曾填过多家 Key 但当前服务商已清空 | 否 |

### 1.3 与聊天设置页的关系

- **设置页**开关/表单看本地已加载的配置(打开助手即可改)。
- **分享页**看服务端返回的公开能力位(`has_web_search_provider`,兼容旧字段 `has_tavily_key`),**不会**把 API Key 下发给嵌入页。

## 2. 设置保存时密钥如何处理

### 2.1 正常保存

在聊天设置中选择服务商并填写 Key 后点保存:配置写入会话存储。再次打开设置页应看到相同服务商与 Key。

### 2.2 切换服务商

切换到另一家服务商时,**此前填写的其他服务商 Key 仍会保留**。再切回来应能直接回填,无需重填。

### 2.3 清空服务商

下拉清空后,联网搜索不可用(设置页与分享页均不应再显示可用联网),但已存 Key 仍保留在配置中,便于稍后重选。

## 3. 错误与拒绝路径

| 场景 | 预期 |
|---|---|
| 分享链接指向不存在或无权访问的助手 | 分享页无有效标题/能力,或接口错误;不伪造「可用联网」 |
| 绕过页面直接 PATCH 非法服务商/缺 Key | 接口 400,明确错误信息(与设置页校验一致) |
| 仅旧版 Tavily Key、从未保存过新服务商字段 | 分享页仍可通过兼容字段识别联网可用 |

## 4. 与旧版本差异

1. 此前分享页只能识别 Tavily Key(`has_tavily_key`);配置了其他服务商时嵌入页可能看不到联网开关 → 现以 `has_web_search_provider` 为准,Tavily 字段仅作回落。
2. 密钥明文不会出现在分享页公开 info 响应中(仅布尔能力位)。
