# 用户手册 — 企业版统一认证进站（开通 + SSO）

适用:agentui 企业版(`authMode=intellect-enterprise`),用户通过**统一认证(SSO)**进入应用并使用 intellect-team 能力。  
本文用业务术语描述可见行为;实现细节见 `docs/auth-intellect-auth-to-team-flow-status.md`。  
账号密码登录的细则仍见 `docs/bff-sso-login-manual.md`。

## 1. 你需要先具备什么

要成功进入工作台,通常需要同时满足:

1. 打开的是已开通企业版的应用地址(未开通企业版时没有「统一认证」进站能力);  
2. 管理员已为你**开通本应用账号**(在统一身份/组织侧完成授权或同步);  
3. 登录页能看到「统一认证」类按钮(渠道已启用)。

仅在统一认证平台注册、但**尚未开通本应用**时:**不能**指望一登录就进入 agentui 工作台。

## 2. 入口

- 未登录访问应用 → 进入登录页(`/login`)。  
- 可选 `/login?tenant=<租户ID>`(多租户/运营场景)。  
- 登录页可见:账号密码区(若未关闭)、**统一认证按钮**、注册入口(若网关允许)。

## 3. 用统一认证登录

### 3.1 正常路径

1. 点击「统一认证」或「Sign in with …」;  
2. 浏览器跳到统一认证页;若你已在统一认证登录过,可能**不再输入密码**;  
3. 认证成功后自动回到应用工作台。  

全程**不需要**复制或粘贴任何 Token。

### 3.2 渠道按钮何时出现

- 后台已启用至少一个可用于登录的统一认证渠道;  
- 渠道未配好时按钮不出现,此时仍可用账号密码(若未关闭);  
- 运营可临时关闭全部统一认证渠道,页面只剩密码登录。

### 3.3 失败时你会看到什么

| 提示含义 | 你可以怎么做 |
|---|---|
| 账号尚未开通 | 联系管理员完成开通/绑定后再试 |
| 账号已被禁用 | 联系管理员 |
| 登录状态已失效 / 登录请求已过期 | 重新点击统一认证按钮 |
| 无权限登录该应用 | 联系管理员检查租户与身份 |
| 请求过于频繁 | 稍后再试 |
| 认证服务暂时不可用 | 稍后再试,或改用账号密码(若可用) |

### 3.4 会话过期后的静默重登

- 应用会话过期但统一认证仍有效时,再次打开应用可能**直接回到工作台**,无需再输密码;  
- 统一认证也过期时,会进入统一认证登录,最多自动尝试一次静默;  
- **主动退出**后再打开应用,会回到登录页,不会被自动登录。

## 4. 账号密码登录(对照)

- 输入的是**本应用**登录名与密码,不是统一认证平台的密码替身;  
- 仅在统一认证注册、从未在本应用设密/开通时,密码登录通常会失败;  
- 成功后同样进入工作台,无需刷新。

## 5. 注册

- 企业版若开启邀请制,注册需要有效邀请码;  
- 注册成功后一般回到登录页,再登录;  
- 在统一认证/组织门户注册**不等于**自动完成本应用开通(见 §1)。

## 6. 登出

- 头像 → 退出:清除本应用登录态并回登录页;  
- 默认**不会**同时退出统一认证平台(是否跳转统一认证登出由部署配置决定)。

## 7. 用户不必关心的事

- 后台是 Rust 还是 Python 网关、Token 字符串、`imt_*` 等技术细节;  
- 管理员如何在组织侧开通/对账——你只需在开通完成后走 §3。

## 8. 不在本手册范围

- 统一认证平台自身的找回密码、申诉;  
- 跨其它产品(如运维平台)的免登录跳转细节;  
- 单点登出(SLO)完整策略。
