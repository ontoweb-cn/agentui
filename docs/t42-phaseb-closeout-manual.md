# 业务手册 — 联网搜索密钥保存与画布 Go 事件

> module: `t42-phaseb-closeout`;日期:2026-11-26
> 读者:使用聊天设置和智能体画布的人

## 1. 保存联网搜索密钥

入口:聊天 → 设置 → 联网搜索,填入供应商和密钥,保存。

| 操作 | 预期 |
|---|---|
| 第一次填入密钥并保存 | 保存请求里带上这份新密钥。Gateway 在同一次保存里写入密钥库并从事会话配置中去掉明文。保存失败时,密钥不会先被改掉 |
| 已配置时留空保存 | 请求里不再带这个空密钥字段,已存密钥保持不变 |
| 换一个新密钥再保存 | 请求里只带新密钥,由同一次保存替换 |
| 选了需要密钥的供应商,但密钥是空的,而且以前也没配过 | 保存被拒绝,并说明缺密钥 |

错误路径:未登录或没有该会话权限时,保存失败,不会把密钥写进别人的会话。

## 2. 画布运行时的事件

入口:智能体画布 → 运行/调试,发送一条消息。

| 上游发来的事件 | 画面上 |
|---|---|
| 节点开始 / 节点结束(原名) | 时间线照旧显示该节点 |
| 普通消息 | 出现在对话里 |
| Go 的 `waiting_for_user` | 出现填写表单,而不是被丢掉 |
| Go 的 `done` | 若本轮还没有流程结束,则补上消息结束和流程结束。若流程结束已经到过,这条 `done` 被忽略,不再结束第二次 |
| Go 的 `cancelled` | 流程结束,并带上已取消标记 |
| Go 的 `error` | 弹出错误说明,不把错误当成一条正常节点 |

Python 画布今天发出的事件名不变,行为与接线前一致。

## 3. 取消

画布上的停止走画布任务取消。聊天里的停止走会话取消。两条路径不合并成同一个按钮语义。

「点停止后 5 秒内节点停住」需要正在跑的 Go 画布。本环境没有该进程,这一条不能在这里验收。

## 4. 本环境做不到的事

- 把历史明文密钥在生产库里迁走(没有生产库权限)
- 轮换加密主密钥(代码在 Gateway 的 Rust 仓库,这台机器上没有)
- 用真实搜索供应商打一次外网
- 在真实浏览器里看 Go 画布跑完一轮
